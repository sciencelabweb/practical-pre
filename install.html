Manual Installation Guide

If the automatic install prompt doesn't appear, follow the steps for your device below.

Android

  1. Open this site in Chrome
  2. Tap the ⋮ menu (top-right)
  3. Select "Install app" or "Add to Home screen"
  4. Confirm by tapping Install

iPhone / iPad

  1. Open this site in Safari
  2. Tap the Share icon (bottom)
  3. Scroll and tap "Add to Home Screen"
  4. Tap Add to confirm

Desktop (PC/Mac)

  1. Open in Chrome or Edge
  2. Click the install icon in the address bar
  3. Or press Ctrl + D / ⌘ + D
  4. Click Install in the popup

Frequently Asked Questions

What is a PWA?

A Progressive Web App (PWA) is a website that installs like a native app. It runs in its own window, works offline, and appears on your home screen — without downloading from an app store.

Does it take up storage?

Very little — typically under 5 MB. Much smaller than a native app, and it caches only the files needed for offline use.

Will I get updates?

Yes! Whenever you open the app with internet, it silently updates in the background. You always get the latest simulators and fixes.

Can I uninstall it?

Absolutely. Just long-press the app icon on your home screen (or use your browser's app settings) and select Uninstall.

Student Tip

Installing ScienceLab as a PWA is perfect for practical exam preparation. You can access all simulators offline during revision sessions, on the bus, or anywhere without worrying about data. It behaves exactly like a native app but uses almost no storage space.
